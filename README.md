## AxManagerD v1.2.0 正式版

> 一款**免 Root**的 Android 设备所有者管理器：不刷机、不解锁 Bootloader、不影响保修与 OTA，就能拿到接近企业级设备管控的能力。

---

## 它能帮你做什么

### 🔒 应用隐藏
把不想被看到的应用从启动器和最近任务里隐藏，应用并未卸载、数据原封不动，需要时一键恢复。

### ⏸️ 应用挂起 / 解挂
进程被停止、图标变灰、无法启动，效果等同卸载但**不删数据**。专治删不掉又天天后台偷跑耗电的应用。

### 🛑 强制停止 / 停用 / 禁用
比系统自带的「强行停止」更彻底，阻断自启动、互相唤醒、后台偷跑流量。

### 🚫 禁止卸载
锁定重要应用，防误删，也防被其他应用恶意卸载（例如防止孩子卸载学习软件）。

### 🎛️ 权限管控
授予或拒绝应用的各种权限（含危险权限），精确掌控每个应用能访问什么。

### 🔄 一键重启
通过设备所有者特权直接重启设备，不受 Android 11+ 电源菜单限制。

### 🧩 运行时模块（Runtime Modules）
内置模块框架，支持自定义脚本模块：系统属性注入（resetprop）、开机自启、定时/阈值触发、传感器采集与数据回传，把 AxManagerD 当成一个「免 Root 的 Magisk」来用。

### 🛠️ Xposed 注入引擎
集成 LSPatch，无需 Root 即可给目标应用「打补丁」，实现运行时 Hook —— 免 Root 用 Xposed 模块的体验。

### 🤖 AI 与脚本追踪
AI 分析引擎只处理**本应用与系统相关**的请求；命令执行过程会被实时追踪，脚本调了哪些命令一目了然，可疑行为可回滚。

### 🔐 新权限通道（DP / WS）
在国产 ROM 大面积阉割 DeviceOwner 的环境下，新增基于系统级 Role / 权限的提权通道，一次授予即可解锁大批设备策略能力；支持查询、撤销与失败原因解释。

### 👤 资料所有者（Profile Owner）
只需管理当前用户、影响面更小、在国产 ROM 上存活率更高，可作为设备所有者不可用时的独立提权通道。

## 使用方法

1. **安装 AxManagerD**：从 [Releases](https://github.com/bufanchen121101/AxManagerD/releases) 下载最新 APK 安装。
2. **激活权限通道**：安装 [Dhizuku](https://github.com/iamr0s/Dhizuku) 或 [Shizuku](https://github.com/RikkaApps/Shizuku)，按应用内引导完成激活。
3. **授权**：打开 AxManagerD，在应用内完成桥接授权。
4. **开始使用**：授权成功后即可在仪表盘里管理应用、加载模块、打补丁。

> 💡 全程无需 Root。激活只需电脑连一次 ADB，之后手机端独立使用。

## 核心原理

AxManagerD 通过系统原生的 DevicePolicyManager（DPM）执行操作，能力等同企业级设备管控，但由你自己掌控：

- ✅ 不解锁 Bootloader、不刷机、不破坏保修
- ✅ 不影响 OTA 系统更新
- ✅ 不被银行 / 游戏等应用的 Root 检测拦截
- ✅ 卸载即完全还原，不留后患
