# AxManagerD

> 🌐 官网 / Official Site: **https://axmd.cc.cd**
> 📦 最新版下载：[Releases](https://github.com/bufanchen121101/AxManagerD/releases)

**AxManagerD 是一个免 Root 的模块化扩展框架。**

它围绕 **Magisk 式的模块系统**打造：不 Root、不刷机、不解锁 Bootloader、不碰系统分区，就能给手机加载模块脚本 —— 注入系统属性、开机自启、执行自定义命令、定时与条件触发、注入 Hook，把「折腾」这件事从刷机 Magisk 变成装个 App。

> 设备所有者（Device Owner）能力只是它的**附加项**：当设备能拿到相应身份时，可以额外获得应用隐藏、挂起、权限管控等系统级管理手段；拿不到也不影响模块系统完整可用。

---

## 一、核心：模块系统

### 🧩 模块框架（Magisk 式）
标准的模块包结构（`module.prop` + `install.sh` / `uninstall.sh` + 自定义脚本），安装即生效、卸载即清理，模块之间互不影响。

### 🧠 运行时模块（Runtime Modules）
模块体系的进阶玩法，与普通模块**物理隔离**（独立 `runtime_plugins/` 目录）：

- 支持 **常驻进程（daemon）**、**一次性执行（oneshot）**、**混合模式**三种运行模型
- 通过 `runtime.json` 声明**传感器采集**（类型、采样间隔）与**触发器**（定时 / 阈值 / 事件）
- 采集结果以结构化数据回传，可以在应用内直接查看模块跑出来的数据
- 适合做电池健康监控、流量统计、状态上报这类「需要一直在后台盯着」的模块

### ⚙️ 属性注入与开机自启
给系统注入 / 修改属性（resetprop）、开机自动执行脚本、批量执行自定义命令 —— 相当于一个免 Root 的 Magisk + 脚本执行器。

### 🛠️ Xposed 注入引擎
集成 LSPatch，无需 Root 即可给目标应用「打补丁」，实现运行时 Hook —— 免 Root 用 Xposed 模块的体验。

### 🤖 AI 与脚本追踪
- **脚本追踪**：模块 / 命令执行时实时抓取它到底调了哪些命令、做了哪些改动，可疑行为可回滚
- **AI 助手**：只处理与本应用、与系统相关的请求（写脚本、查命令、排查问题），闲聊写作之类一律拒绝

## 二、附加：设备所有者能力

当设备具备 **Device Owner / Profile Owner / DP** 等身份时，AxManagerD 会额外解锁一批系统级管理功能：

| 能力 | 说明 |
|------|------|
| 🔒 **应用隐藏** | 从启动器和最近任务里隐藏应用，不卸载、不丢数据，可一键恢复 |
| ⏸️ **应用挂起 / 解挂** | 进程停止、图标变灰、无法启动，效果等同卸载但不删数据 |
| 🛑 **强制停止 / 停用 / 禁用** | 比系统自带「强行停止」更彻底，阻断自启动与互相唤醒 |
| 🚫 **禁止卸载** | 锁定重要应用防误删，也防被其他应用恶意卸载 |
| 🎛️ **权限管控** | 授予或拒绝应用的各种权限（含危险权限） |
| 🔄 **一键重启** | 直接重启设备，不受 Android 11+ 电源菜单限制 |

**多种权限通道，自动适配机型**：优先使用设备所有者（DO），其次资料所有者（PO），再退到 DP 角色 / ADB 通道；国产 ROM 上拿不到设备所有者也能用低一档的方式激活，激活前会给出无副作用的探测与失败原因说明。

> ⚠️ 这部分是**可选增强**：不激活设备所有者，模块、Hook、脚本追踪等核心功能照常使用。

## 适合谁用

| 场景 | 说明 |
|------|------|
| **模块折腾党** | 想要 Magisk 式的模块化扩展，但不想刷机、不想破坏保修 |
| **开发者 / 进阶用户** | 自定义脚本、属性注入、定时任务、运行时数据采集 |
| **免 Root Xposed 用户** | 需要运行时 Hook，又不想动系统分区 |
| **精简系统 / 省电流量** | 隐藏、冻结、停用预装应用与后台偷跑的应用（需设备所有者能力） |
| **隐私与家长管控** | 精确管控权限、锁定重要应用防误删（需设备所有者能力） |

## 使用方法

1. **安装 AxManagerD**：从 [Releases](https://github.com/bufanchen121101/AxManagerD/releases) 下载最新 APK 安装。
2. **加载模块**：在应用内导入 / 安装模块包，或直接安装运行时模块，按模块说明配置 `runtime.json` 与触发器。
3. **（可选）开启设备所有者能力**：安装 [Dhizuku](https://github.com/iamr0s/Dhizuku) 或 [Shizuku](https://github.com/RikkaApps/Shizuku)，按应用内引导完成激活与授权，即可使用应用管理相关功能。

> 💡 全程无需 Root。设备所有者激活只需电脑连一次 ADB，之后手机端独立使用。

---

## 核心原理

- **模块**：模块脚本在 AxManagerD 提供的运行环境中执行，管理器负责安装、启动、守护与数据回收；运行时模块由前台服务常驻托管，进程退出后可自动拉起。
- **设备所有者**：通过系统原生的 DevicePolicyManager（DPM）执行操作，能力等同企业级设备管控，但由你自己掌控。
- ✅ 不解锁 Bootloader、不刷机、不破坏保修
- ✅ 不影响 OTA 系统更新
- ✅ 不被银行 / 游戏等应用的 Root 检测拦截
- ✅ 卸载即完全还原，不留后患
